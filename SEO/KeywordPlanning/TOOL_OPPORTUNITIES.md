## The strategic argument for building these

1. **Traffic moat.** Tools earn backlinks naturally - people cite a calculator in blog posts. Guides rarely earn backlinks. Every tool we ship shifts domain authority.

2. **Product discovery funnel.** Free tool -> authenticated user -> guided course recommendation -> paid tier. The Product Blueprint already defines this motion.

3. **LLM-era differentiation.** Tools require interaction. LLMs summarize guides, but they cannot replace a calculator. Tool pages survive AI traffic cannibalization better than explainer pages.

4. **Compound with guides.** Every guide we ship should embed the matching tool. Guide reader converts 5-10x higher when the action is one click away.
